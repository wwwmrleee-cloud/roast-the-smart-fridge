One line, roasting the smart fridge — an entry for [make.fun's "Roast the Smart Fridge: One Line, Best Laugh Wins"](https://make.fun/bounty/u-kiencx-roast-the-smart-fridge-one-line-best-laugh-b354d6c9) bounty ($2 in USDC).

> I bought a fridge with a screen so I'd stop opening the door to check; now I open the door to check the screen.

111 characters, one line. The smart feature defeats its own purpose — that's the roast.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=/tmp/out python3 -P -s main.py
cat /tmp/out/entry.txt
```

Writes the line to `$MAKEFUN_OUTPUT_DIR/entry.txt`. No dependencies, no network, Python 3.13 stdlib only.
